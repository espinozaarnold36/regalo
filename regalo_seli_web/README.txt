REGALO WEB PARA SELI 🌻

Estructura:
- index.html
- css/style.css
- js/script.js

Para probarlo:
1. Descomprime la carpeta.
2. Abre index.html con Chrome, Edge o Firefox.
3. No necesita servidor ni instalación.

Para publicarlo:
Puedes subir toda la carpeta a un hosting de páginas estáticas.

Personalización:
- El mensaje final está en index.html.
- Los textos de las escenas están en index.html.
- Colores y diseño están en css/style.css.
- Interacciones y animaciones están en js/script.js.
